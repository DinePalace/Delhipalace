======================================================================
HOW TO DEPLOY
======================================================================
HOSTINGER / cPANEL
  1. Open File Manager, go into public_html.
  2. Delete or back up what is there now (WordPress site = take a
     full backup first).
  3. Upload EVERYTHING that is inside the repo's public_html folder:
     index.html, 404.html, favicon.ico, llms.txt, robots.txt,
     sitemap.xml, the assets folder, and each page folder
     (about, menu, order, gallery, contact, blog, privacy-policy,
     best-indian-food-brantford, brantford-takeout-delivery,
     chinese-food-brantford, vegetarian-indian-food-brantford,
     what-is-hakka-cuisine). Each page folder contains index.html.
     The site root index.html must sit directly inside public_html,
     not inside an extra sub folder.
  4. Visit https://thedelhipalace.ca and click through the menu.

CLOUDFLARE PAGES (DinePalace/Delhipalace repo)
  The site files already live in public_html/. Push to main.
  Pages settings: no build command, output directory public_html.
  wrangler.jsonc points static assets at ./public_html and still
  handles trailing-slash URLs and the 404 page.

PREVIEW ON YOUR OWN COMPUTER
  Pages are folder/index.html (menu/index.html, about/index.html, ...).
  Links are absolute (/menu/), so open the site through a static server
  that serves each folder's index.html. preview-server.js still expects
  the older menu.html files.
